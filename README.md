# pharmaobservatory-cli

`po`, the Pharma Observatory command line client. This is the scaffold: only
`po version` exists so far. The full README comes later.

## Build from source

Requires Go 1.24 or newer.

```sh
go build -o po ./cmd/po
./po version
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for tests, lint and the release dry run.
